# Network Automation Engineer -- UTN-FRC

## Material de clases

### Código

- Python: ejemplos basicos que muestran como crear e importar scripts y clases Python
- json: ejemplos de serializacion y des serializacion. Manejo de archivos JSON y Diccionarios
- yaml: manejo de archivos YAML
- Ansible: ejemplos de codido Ansible
- Netmiko: ejemplos de codigo Netmiko

#### Netmiko

- **Netmiko**: Ejemplos de configuracion con Netmiko
- **integrador1.py**: ejercicio integrador Netmiko Part1 (send show commands)
- **integrador2.py**: ejercicio integrador Netmiko Part1 (send config commands)
- **sim_caso**: simulacion CU automatizacion Data Center Network

#### Modelado

- **Modelado**: Modelo de Datos de un CU
- **json_schema**: estructura y restricciones de los datos de un CU
- **reutilización**: reutilizacion de datos en YAML

#### Ansible

- **ejemplo1**: ejemplos de playbooks de utilización y visualización de variables
- **ejemplo2**: ejepmlos de playbooks sobre estructuras de programación de Ansible (when, loop, book/rescue, etc.)
- **invantarios**: ejemplo de inventario INI
- **variables**: variables tipo host_var y group_var. Lugares de definición y precedencia de las variables
- **debug**: niveles de debug de ansible
- **contexto**: modulos, lugar donde estan los modulos, coleciones de modulos
- **ssh-config**: configuracion SSH para compatibilizar metodos de cifrado y encripción entre Ansible y los dispositivos simulados
